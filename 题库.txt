第1题
【题目】求函数 f(x) = 3x^4 - 4x^3 + 2 的极值。
【答案】极大值 f(0)=2，极小值 f(1)=1。
【解析】f'(x)=12x^3-12x^2=12x^2(x-1)。令 f'(x)=0 得 x=0 或 x=1。二阶导 f''(x)=36x^2-24x。f''(1)=36-24=12>0，故 x=1 为极小值点，f(1)=1。f''(0)=0，需用第一判别法：x=0 两侧 f' 同号（均为负），故 x=0 不是极值点。但检查 x<0 时 f' 为负，x∈(0,1) 时 f' 也为负，x>1 时 f' 为正，所以 x=0 处无极值。重新验证：实际上 x=0 处导数不变号，确实非极值。极大值在边界无定义域限制时不存在。修正：本题极小值 f(1)=1。

第2题
【题目】计算不定积分 ∫(2x + cos x) dx。
【答案】x^2 + sin x + C。
【解析】利用线性性质分别积分：∫2x dx = x^2，∫cos x dx = sin x，合并加常数 C。

第3题
【题目】求极限 lim[x→0] (sin x) / x。
【答案】1。
【解析】这是经典重要极限。当 x→0 时，sin x ~ x，故比值为 1。也可用洛必达法则：分子分母都趋于 0，求导后 lim cos x / 1 = 1。

第4题
【题目】求函数 f(x) = e^(2x) 的导数。
【答案】f'(x) = 2e^(2x)。
【解析】利用链式法则，外层 e^u 导数为 e^u，内层 2x 导数为 2，相乘得 2e^(2x)。

第5题
【题目】判断级数 Σ[1/n^2] (n=1到∞) 的收敛性。
【答案】收敛，和为 π²/6。
【解析】这是 p-级数，p=2>1 故收敛。其和为著名的巴塞尔问题结果 π²/6。

第6题
【题目】求函数 f(x,y) = x²y + y³ 的偏导数 ∂f/∂x 和 ∂f/∂y。
【答案】∂f/∂x = 2xy，∂f/∂y = x² + 3y²。
【解析】对 x 求偏导时把 y 当常数：∂(x²y)/∂x = 2xy，∂(y³)/∂x = 0。对 y 求偏导时把 x 当常数：∂(x²y)/∂y = x²，∂(y³)/∂y = 3y²。

第7题
【题目】求定积分 ∫[0到1] x² dx。
【答案】1/3。
【解析】∫x² dx = x³/3，代入上下限：1³/3 - 0³/3 = 1/3。

第8题
【题目】求函数 y = ln(3x+1) 的导数。
【答案】y' = 3/(3x+1)。
【解析】链式法则：外层 ln u 导数 1/u，内层 3x+1 导数 3，相乘得 3/(3x+1)。

第1题
【题目】解释什么是递归，并给出一个递归求阶乘的 Python 示例。
【答案】递归是函数调用自身的编程技巧。阶乘示例：def fact(n): return 1 if n<=1 else n*fact(n-1)。
【解析】递归需有基线条件（n<=1 返回 1）和递归条件（n*fact(n-1)）。每次调用将问题规模缩小，直到到达基线。

第2题
【题目】Python 中列表和元组有什么区别？
【答案】列表可变（mutable），元组不可变（immutable）。列表用 []，元组用 ()。
【解析】列表支持增删改（append/pop/赋值），元组创建后不能修改。元组因不可变，可作为字典键、集合元素，且访问略快。

第3题
【题目】什么是时间复杂度？O(n) 和 O(n²) 的区别？
【答案】时间复杂度描述算法运行时间随输入规模增长的趋势。O(n) 线性增长，O(n²) 平方增长。
【解析】遍历一个长度 n 的列表是 O(n)；嵌套遍历（双重循环）是 O(n²)。当 n=1000 时，O(n) 约 1000 步，O(n²) 约 100万步。

第4题
【题目】解释什么是 RESTful API。
【答案】RESTful API 是基于 HTTP 协议、遵循 REST 架构风格的接口设计，用 GET/POST/PUT/DELETE 对应资源增删改查。
【解析】REST 强调资源（用 URL 标识）和无状态通信。GET 查询、POST 新建、PUT 更新、DELETE 删除，状态码 200/201/400/404 表示结果。

第5题
【题目】写一个 Python 函数，判断一个数是否为素数。
【答案】def is_prime(n): return n>1 and all(n%i!=0 for i in range(2,int(n**0.5)+1))。
【解析】素数是大于1且只能被1和自身整除的数。只需检查到 √n，因为因子成对出现。all() 在所有条件满足时返回 True。

第6题
【题目】什么是面向对象编程的三大特性？
【答案】封装、继承、多态。
【解析】封装：将数据和方法组合在类中，隐藏内部实现；继承：子类复用父类的属性和方法；多态：同一接口不同实现，如父类引用调用子类方法。

第7题
【题目】解释 Python 中 == 和 is 的区别。
【答案】== 比较值是否相等，is 比较是否为同一对象（内存地址）。
【解析】a=[1,2]; b=[1,2] 则 a==b 为 True（值相同），a is b 为 False（不同对象）。小整数缓存池使 a=1;b=1 时 a is b 为 True。

第8题
【题目】什么是 Git 中的分支？如何创建并切换分支？
【答案】分支是指向提交的指针，允许多条开发线并行。创建并切换：git checkout -b 分支名。
【解析】Git 分支轻量，本质是指向某次提交的可变指针。master/main 是默认分支。-b 表示创建并切换一步完成。

【英语学习】

第1题
【题目】辨析 affect 和 effect 的区别。
【答案】affect 是动词"影响"，effect 是名词"效果/影响"。
【解析】例：The weather affects my mood.（天气影响心情）；The effect is obvious.（效果明显）。记忆口诀：RAVEN——Remember Affect Verb Effect Noun。

第2题
【题目】现在完成时和一般过去时的区别是什么？
【答案】一般过去时强调过去某个时间发生的动作；现在完成时强调过去动作对现在的影响，结构 have/has+过去分词。
【解析】I lost my keys（过去丢了，可能已找到）；I have lost my keys（丢了到现在还没找到，影响现在）。现在完成时不能搭配具体过去时间。

第3题
【题目】翻译并解释 "It is no use crying over spilt milk"。
【答案】覆水难收 / 牛奶洒了哭也没用。
【解析】It is no use + doing 是固定句型，表示"做某事无意义"。spilt milk 象征已发生不可挽回的事，寓意不要为无法改变的事后悔。

第4题
【题目】用定语从句改写：The book is interesting. I bought it yesterday.
【答案】The book which/that I bought yesterday is interesting.
【解析】which/that 指代物，在从句中作宾语时可省略。先行词 The book 是物，用 which 或 that 连接。

第5题
【题目】辨析 few / a few / little / a little。
【答案】few 修饰可数名词表"很少几乎没有"；a few 表"有一些"；little 修饰不可数名词表"很少几乎没有"；a little 表"有一点"。
【解析】口诀：可数用 few/a few，不可数用 little/a little；有 a 表示"有一些"（肯定），无 a 表示"几乎没有"（否定）。例：a few books（几本书），little water（几乎没水）。

第6题
【题目】解释虚拟语气：If I were you, I would study harder.
【答案】如果我是你，我会更努力学习。（与现在事实相反的虚拟语气）
【解析】与现在事实相反：条件句用过去式（be 动词一律用 were），主句用 would+动词原形。事实是我不是你，所以是虚拟。

第7题
【题目】写出 "by" 的三种常见用法。
【答案】① 表示方式/手段 by doing sth（通过做某事）；② 表示时间"到...为止" by the time；③ 被动语态 be done by sb（被某人...）。
【解析】例：learn English by reading（通过阅读学英语）；by 5pm（到下午5点前）；written by him（被他写的）。

第8题
【题目】辨析 used to do 和 be used to doing。
【答案】used to do 表示过去常常做（现已不做）；be used to doing 表示习惯于做某事。
【解析】I used to get up early（过去早起，现在不早起了）；I am used to getting up early（我已习惯早起）。注意 be used to 后接 doing。

【大学物理】
========================================

第1题
【题目】牛顿第二定律的内容是什么？
【答案】物体加速度与所受合外力成正比，与质量成反比：F = ma。
【解析】F 为合外力（N），m 为质量（kg），a 为加速度（m/s²）。力的方向与加速度方向相同。说明了力是改变运动状态的原因，而非维持运动的原因。

第2题
【题目】解释动量守恒定律。
【答案】系统不受外力或所受合外力为零时，系统总动量保持不变。
【解析】碰撞、爆炸等问题中常用。即使内力很大，只要合外力为零，总动量 p=m₁v₁+m₂v₂=常数。例：两个物体碰撞前后的动量之和相等。

第3题
【题目】什么是简谐运动？写出其运动方程。
【答案】物体在回复力 F=-kx 作用下的运动，位移随时间按正弦规律变化：x=A cos(ωt+φ)。
【解析】A 为振幅，ω 为角频率，φ 为初相位。回复力与位移成正比且方向相反，如弹簧振子、单摆（小角度）。周期 T=2π/ω。

第4题
【题目】解释光的折射定律（斯涅尔定律）。
【答案】n₁ sin θ₁ = n₂ sin θ₂，入射角正弦与折射角正弦之比等于介质折射率之比。
【解析】光从光疏介质进入光密介质时向法线偏折。n 为折射率，θ 为与法线的夹角。应用：透镜成像、光纤全反射。

【数据结构】
========================================

第1题
【题目】什么是栈？栈的特点是什么？
【答案】栈是只允许在一端进行插入和删除的线性数据结构，特点是后进先出（LIFO）。
【解析】栈顶（top）是唯一操作端。push 入栈、pop 出栈。应用：函数调用栈、括号匹配、表达式求值、浏览器后退。

第2题
【题目】什么是队列？队列的特点是什么？
【答案】队列是允许在一端插入、另一端删除的线性结构，特点是先进先出（FIFO）。
【解析】队尾（rear）入队，队头（front）出队。应用：任务调度、消息队列、BFS广度优先搜索。

第3题
【题目】二分查找的时间复杂度是多少？前提条件是什么？
【答案】时间复杂度 O(log n)，前提是数据有序（升序或降序）。
【解析】每次比较中间元素，缩小一半范围。n 个元素最多比较 log₂n 次。例：1000个元素约10次，100万个元素约20次。

第4题
【题目】什么是二叉搜索树（BST）？
【答案】左子树所有节点值<根节点值<右子树所有节点值的二叉树，中序遍历得有序序列。
【解析】查找/插入/删除平均 O(log n)，最坏退化为 O(n)（如有序插入成链表）。平衡树（AVL、红黑树）保证 O(log n)。

第5题
【题目】冒泡排序和快速排序的时间复杂度分别是多少？
【答案】冒泡排序 O(n²)，快速排序平均 O(n log n)、最坏 O(n²)。
【解析】冒泡每轮比较相邻元素交换，n 轮；快排选基准分区递归，平均高效。快排在工程中常优于冒泡，且可用尾递归优化空间。
